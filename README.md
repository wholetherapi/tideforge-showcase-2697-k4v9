# Tideforge Collective - Prototype Catalogue

Static showcase for the collective's open instrument prototypes. Every project
page is a Markdown file in `content/projects/` with YAML front matter; the site
generator publishes them from the default branch.

Editorial rules:

- Front matter must stay valid YAML.
- Project pages are updated only during a catalogue release cycle.
- A `design_package_url` may be present only when the design package has actually
  been released under the collective's own repository account.
